# Product Sales and Customer Insights Data Analysis

## Project overview
Analyze retail sales data to understand product performance, monthly trends, regional sales, and new vs returning customer contribution.

## Dataset
The included dataset has 45 synthetic sample sales records from Jan-Jun 2026. It contains no real customer personal information.

## Tools
- Python
- Pandas
- Matplotlib
- Google Colab / Jupyter Notebook

## Metrics
- Revenue = Quantity × Unit Price
- Cost = Quantity × Unit Cost
- Profit = Revenue − Cost
- Profit Margin (%) = Profit / Revenue × 100

## Run
1. Put `product_sales_customer_insights.csv` in the same folder as your notebook.
2. Install packages if needed: `pip install pandas matplotlib`
3. Run the Python code in the project report or notebook cell by cell.

## Important
The dataset is synthetic and intended for learning/demo purposes only. Replace it with an approved real dataset if your faculty requires real retail data.
